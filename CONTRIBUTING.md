# Contributing

Run `python .claude/hooks/test_hooks.py` before opening a PR — all 43 tests need to pass.

Hooks are stdlib-only and Python 3.8+. No third-party deps, ever.

If you're touching hook behavior, skim `docs/WORKFLOW.md` and `docs/AUTOMATION.md` first — a few rules there are load-bearing.

Issues: drop your OS, Python version, and a repro.
